# DeskButler

DeskButler 是一个完全在本机运行的 Windows 工作现场管家。当前首个模块会保存普通可见窗口、资源管理器目录和窗口布局，并让你在重启或重新登录后手动恢复；它不会自动恢复，也不会关闭现有程序。

## 当前状态

这是 **0.1.0 本地 release candidate（自动化候选）**，尚未正式发布，也没有配置远程 Git。本轮最终 Release 自动套件为 653 项：650 通过、3 项按显式交互/长时门禁跳过、0 失败；Release build 为 0 警告、0 错误。Windows 10/11 专用 VM 的 QQ、微信、富途全链、干净测试账户安装与卸载、真实重启、本构建 30 分钟资源测试、诊断 ZIP 用户导出和产品签名仍未过门禁。不要把当前状态理解为“全面兼容”或“已正式发布”。

详细状态见 [兼容性与发布门槛](docs/compatibility.md)。

## 安装与启动

1. 先运行 `scripts\verify-release.cmd` 生成并验证安装器。
2. 双击 `artifacts\installer\DeskButler-Setup-0.1.0.exe`。
3. 安装器按当前用户安装到 `%LOCALAPPDATA%\Programs\DeskButler`，不要求管理员权限。
4. 从开始菜单打开“DeskButler”。应用通常只显示在任务栏通知区域；双击托盘图标可打开主窗口。

当前安装器未做产品代码签名。若 Windows 显示来源提示，请先核对本次验证脚本输出的 SHA-256，不要从未知来源获取安装包。

本轮最终安装器为 `artifacts\installer\DeskButler-Setup-0.1.0.exe`，大小 **64,531,942 字节**，SHA-256 **`893CDAAA1B467B690B27B4DCB9C433C9606C55968045D5D5C8E1D90CA193FD17`**。

## 第一次使用：文字截图流程

```text
[任务栏右下角 DeskButler 图标]
  ├─ 保存当前现场
  ├─ 最近现场 > 2026-08-25 09:30:00 · 3 个窗口
  ├─ 暂停捕获 / 继续捕获
  ├─ 聚焦恢复卡
  ├─ 打开管家
  └─ 退出
```

```text
[主窗口] 首页 | 现场 | 模块 | 设置 | 诊断
  首页：立即保存现场、暂停/继续捕获
        手动保存后确认发现的常驻候选（高可信默认勾选、低可信默认不选）
  现场：最近 3 次现场、刷新、恢复
  设置：常驻总开关、查找/浏览添加、立即启动、常驻列表、永久排除路径
  诊断：查看健康状态、预览脱敏日志
```

```text
[发现的常驻应用]
  ☑ 高可信新应用       [浏览修正主程序 .exe]
  ☐ 低可信/helper 候选 [浏览修正主程序 .exe]
  [确认添加] [本次忽略]

[常驻应用列表（下次登录自动顺序）]
  应用名 · 启动路径 · 路径状态
  [启用/停用] [上移/下移] [替换路径] [删除]
  [立即启动常驻应用]
```

```text
[恢复卡]
  ☑ 窗口 A        [永久排除]
  ☑ 窗口 B        [永久排除]
  [立即恢复] [安全恢复] [跳过]
```

恢复卡等待 15 秒只会隐藏，绝不会自行恢复。错过后可从托盘“最近现场”或主窗口“现场”页手动恢复。

每次首实例启动只要存在最新有效快照就会提示。检测到上次异常退出时，自动捕获额外进入运行期安全暂停，但历史、诊断和显式恢复仍可使用；恢复结果按成功、跳过、失败、取消逐项汇总，失败原因保留供重试。设置页可事务式切换当前用户登录启动。

常驻应用与现场恢复相互独立：用户确认的启用项在每个 Windows 登录会话按保存顺序自动处理一批，已有任一已知产品进程时跳过。用户主动退出后，仅重启 DeskButler 不会再次拉起；“立即启动常驻应用”是当前登录内的显式例外。增删、启停、改序或换路径从下次 Windows 登录起自动生效。

完整操作与限制见 [用户指南](docs/user-guide.md)，本地数据说明见 [隐私说明](docs/privacy.md)，问题处理见 [故障排除](docs/troubleshooting.md)。

## 开发与发布验证

先决条件：Windows x64、.NET SDK 10.0.400 或更高版本、官方 Inno Setup 7.1.0。

```bat
scripts\verify-release.cmd
```

脚本依次 restore、Release build、Release test、自包含 win-x64 publish、编译安装器并输出安装器 SHA-256，任一步失败都会立即退出。`artifacts\` 是本机生成目录，不进入 Git。
