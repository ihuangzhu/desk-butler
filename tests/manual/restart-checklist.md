# 真实重启恢复验收清单

此流程包含真实重启。自动化测试和开发代理必须停在“立即重启”之前；只有用户当下明确确认后，才由用户手动重启。不得调用 `shutdown`、`Restart-Computer`、注销或等价命令。

## 重启前准备

- [ ] 记录 OS edition/version/build、DPI、显示器布局、测试账户、当前时间。
- [ ] 记录安装器文件名、版本、大小和 SHA-256；记录 DeskButler 与 TestWindow fixture 版本/hash。
- [ ] 确认在专用测试账户；运行 clean-account 门禁及安装/升级链，没有任何 `BLOCK`。
- [ ] 打开两个受控 TestWindow 和唯一临时 Explorer 目录；记录 PID、HWND、路径及物理像素矩形。
- [ ] 等待快照，记录 snapshot id/时间；确认数据库仅 3 份有效快照。
- [ ] 确认登录自启动启用、`run.lock` 正常、诊断目录可写。
- [ ] 保存所有其他工作，关闭与验收无关的个人应用。
- [ ] 到达此行后状态记为 `NEEDS_USER_CONFIRMATION`，等待用户当下明确确认。
- [ ] **立即重启（仅用户手动执行）**。

## 登录后验证

- [ ] 记录登录时间；确认 DeskButler 单实例自启动且未出现崩溃循环。
- [ ] 恢复卡出现；不操作并完整等待 15 秒，确认卡片收起且没有自动启动或移动任何窗口。
- [ ] 打开管家，确认刚才 snapshot 仍在最近 3 次中；从主界面手动选择恢复。
- [ ] 确认两个缺失 TestWindow 与唯一 Explorer 目录返回，窗口相对记录/DPI 的四边误差均不超过 8 物理像素。
- [ ] 再执行一轮并中途取消；确认后续动作停止、已启动窗口不被关闭。
- [ ] 仅关闭记录的 fixture PID/HWND，并删除唯一临时目录；不得按名称关闭其他进程或 Explorer。
- [ ] 导出脱敏诊断包，记录 bundle id、文件 SHA-256、恢复结果和任何 FAIL/BLOCK。
