# Windows 11 发布验收清单

此清单必须在真实 Windows 11 x64 或独立 Windows 11 VM 中重新执行，禁止复用 Windows 10 结果。当前状态：`PENDING — 当前机器不是 Windows 11`。

- [ ] 记录 Windows 11 edition、版本、完整 OS build、x64、测试账户和机器/VM 标识。
- [ ] 记录所有显示器设备名、主屏、工作区负/正坐标、分辨率及每屏缩放/DPI；至少覆盖单屏与不同 DPI 多屏。
- [ ] 记录安装器版本、文件大小、SHA-256；0.1.0 基准 SHA-256 为 `9935FACC1B2C194E9C1609A28A7EE57A24BEB20A94448D28805FA33C10B7B29C`。
- [ ] 记录 TestWindow fixture build/hash、两个 PID/HWND 和唯一 Explorer 临时路径。
- [ ] 验证捕获、三份快照、缺失显示器回收、两个窗口误差均不超过 8 物理像素。
- [ ] 登录恢复卡显示后完整等待 15 秒；确认绝不自动恢复，随后从主界面手动恢复。
- [ ] 验证恢复取消不回滚已完成动作，也不继续启动后续项目。
- [ ] 验证键盘焦点可见、Tab 顺序、Enter/Space、恢复详情和取消。
- [ ] 导出脱敏诊断包并记录 bundle id 与 SHA-256。
- [ ] 在干净专用账户验证安装、严格更高版本覆盖升级、保留卸载、重装、交互选择删除卸载；无关 HKCU Run 值不变。
- [ ] 实际运行完整 30 分钟资源测试，附每分钟 CSV/JSON；最后 5 次句柄不严格单调增长且数据库仅 3 份有效快照。
- [ ] 执行 `restart-checklist.md` 全流程并记录重启前后时间、快照 id 和结果。
- [ ] 对每项记录 PASS/FAIL/BLOCK；发布前由独立执行人签署 Windows 11 基线。
